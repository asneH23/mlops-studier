# 🌾 MLOps-studier

Mitt studiekod-repo kopplat till Stardew-Ops.

## Commit-format för XP
Använd conventional commits med kursens ID som scope:

```
feat(python): beskrivning    → 50 XP
fix(linux): beskrivning      → 25 XP  
test(ml): beskrivning        → 35 XP
docs(docker): beskrivning    → 10 XP
```

## Kurs-mappar
- `python/`  — Pythonprogrammering
- `linux/`   — Linuxadministration
- `ml/`      — ML-modeller & ramverk
- `docker/`  — MLOps & moln
